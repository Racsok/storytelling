# PROTOCOLO HUMANO

**FADE IN:**

### INT. HABITACIÓN DE ÉL - MAÑANA

Una habitación casi geométrica.

La cama está tendida con precisión matemática. Los libros forman una columna perfecta sobre el escritorio. No hay fotografías. No hay pósteres. No hay objetos que parezcan importantes.

ÉL, 19 años, delgado, rostro inexpresivo, permanece sentado frente al computador.

La luz gris de la mañana entra por una persiana a medio cerrar y divide su cara en franjas.

En la pantalla:

**"CÓMO HACER AMIGOS."**

Debajo, una lista.

— Sonreír.
— Hacer preguntas.
— Escuchar.
— Hacer contacto visual.
— No hablar demasiado de uno mismo.

Él observa la lista.

Toma un bolígrafo.

Escribe debajo:

**"¿OBJETIVO?"**

Piensa.

Añade:

**"TENER AMIGOS."**

Se queda mirando la frase.

No sonríe.

Cierra el computador.

### INT. PASILLO DEL INSTITUTO - DÍA

Un río de estudiantes.

Abrazos. Gritos. Risas. Golpes amistosos en los hombros. Personas que se interrumpen para contar cosas que aparentemente no son importantes y, sin embargo, todos consideran urgentísimas.

Él camina entre ellos con los brazos pegados al cuerpo.

Observa.

Una chica se ríe.

Un chico le dice algo al oído a otro.

Dos amigos chocan las manos.

Él mira la escena como un científico frente a una especie desconocida.

En una puerta cercana, un estudiante deja caer sus cuadernos.

Él se detiene.

Mira los cuadernos.

Mira al estudiante.

No hace nada.

El estudiante recoge sus cosas.

Él continúa caminando.

### INT. CAFETERÍA - DÍA

Ruido de bandejas, sillas arrastrándose y conversaciones superpuestas.

Él está solo en una mesa.

Mastica lentamente.

En la mesa de enfrente, TRES ESTUDIANTES conversan.

Él recuerda su lista.

**Hacer preguntas.**

Se levanta.

Camina hasta ellos.

Se queda de pie.

Los tres levantan la mirada.

```
                            ÉL
                ¿Puedo sentarme?
```

Silencio.

Uno de ellos, MARCOS, sonríe incómodo.

```
                            MARCOS
                Eh... sí, claro.
```

Él se sienta.

Silencio.

Mastica.

Pasan cinco segundos.

```
                            ÉL
                ¿De qué hablan?
```

Los tres se miran.

```
                            CHICA
                De... nada.
```

Él asiente.

Otro silencio.

```
                            ÉL
                Entonces, ¿por qué hablan?
```

La chica deja de sonreír.

Marcos mira su teléfono.

```
                            MARCOS
                Creo que vamos a sentarnos allá.
```

Los tres levantan sus bandejas y se marchan.

Él los observa.

No parece dolido.

Saca su bolígrafo.

En una libreta escribe:

**ERROR 01.**

Debajo:

**"NO PREGUNTAR POR QUÉ LA CONVERSACIÓN EXISTE."**

Se queda pensativo.

Después añade:

**"LAS PERSONAS PUEDEN HABLAR SIN TENER UN PROPÓSITO."**

Mira la frase.

Por primera vez, casi sonríe.

Casi.

### INT. BIBLIOTECA - TARDE

Luz cálida, polvo suspendido en los haces que atraviesan los ventanales.

Él estudia.

A unos metros, LUCÍA, 19, lee un libro.

Él levanta la vista.

Recuerda otra regla.

**Escuchar.**

Se acerca.

```
                            ÉL
                ¿Qué estás leyendo?

                            LUCÍA
                Una novela.
```

Él mira la portada.

```
                            ÉL
                Lo sé.
```

Lucía arquea una ceja.

```
                            LUCÍA
                ¿Entonces?
```

Él tarda en entender.

```
                            ÉL
                Quería saber si te gusta.
```

Lucía sonríe.

```
                            LUCÍA
                Sí. Mucho.
```

Él asiente.

```
                            ÉL
                ¿Por qué?
```

Lucía comienza a explicarlo.

Habla durante casi un minuto.

Él escucha inmóvil.

No interrumpe.

No mira el teléfono.

Cuando ella termina:

```
                            ÉL
                Entiendo.
```

Pausa.

```
                            ÉL
                Yo no leería eso.
```

La sonrisa de Lucía desaparece.

```
                            LUCÍA
                Ah.
```

Él espera.

```
                            ÉL
                ¿He dicho algo incorrecto?

                            LUCÍA
                No.
```

Se levanta.

Recoge su libro.

```
                            LUCÍA
                Pero podrías haber dicho que sonaba interesante.
```

Él mira cómo se aleja.

En su libreta:

**ERROR 02.**

Debajo:

**"NO TODA VERDAD NECESITA SER PRONUNCIADA."**

Piensa.

Tacha "verdad".

Escribe:

**"LAS PERSONAS QUIEREN SABER CÓMO LAS HACE SENTIR LO QUE DICEN, NO SOLO SI ES LÓGICO."**

Cierra la libreta.

### MONTAGE - VARIOS LUGARES - DÍAS

— Él practica sonreír frente al espejo.

Sonríe demasiado.

Su expresión parece la de un vendedor de seguros.

Anota:

**"MENOS DIENTES."**

— En un pasillo, alguien dice:

```
                            ESTUDIANTE
                ¿Qué tal?

                            ÉL
                ¿Qué quieres decir exactamente?
```

El estudiante lo mira.

```
                            ESTUDIANTE
                Nada.
```

Se va.

En la libreta:

**"NO ES UNA PREGUNTA LITERAL."**

— En un autobús, una mujer bosteza.

Él le ofrece una botella de agua.

```
                            MUJER
                No, gracias.
```

Él la retira inmediatamente.

```
                            ÉL
                Entendido.
```

La mujer lo mira, confundida.

Él anota:

**"EL TONO IMPORTA."**

— Frente al espejo.

Practica.

```
                            ÉL
                Hola, ¿cómo estás?
```

Más relajado.

```
                            ÉL
                ¡Hola! ¿Cómo estás?
```

Más casual.

```
                            ÉL
                ¿Qué tal?
```

Se detiene.

```
                            ÉL
                ...Esto es ridículo.
```

Silencio.

Vuelve a intentarlo.

### INT. AULA - MAÑANA

Él entra.

Algo ha cambiado.

Su postura ya no es rígida. Saluda a dos personas de camino a su asiento.

```
                            ÉL
                Buenas.
```

Le responden.

```
                            ESTUDIANTE
                Buenas.
```

Él se sienta.

No parece feliz.

Pero ya no parece perdido.

### INT. CAFETERÍA - MEDIODÍA

Mismo lugar.

Esta vez, Él se acerca a otra mesa.

Hay cinco estudiantes.

Se detiene.

Sonríe apenas.

```
                            ÉL
                ¿Hay sitio?

                            MARCOS
                Sí.
```

Él se sienta.

Alguien cuenta una anécdota.

Él escucha.

Cuando todos ríen, Él ríe medio segundo después.

Mira alrededor.

Imita el volumen de los demás.

Cuando alguien habla, asiente.

Cuando alguien termina, responde:

```
                            ÉL
                ¿Y qué pasó después?
```

La conversación fluye.

Él observa.

Funciona.

Una chica le pregunta:

```
                            CHICA
                ¿Tú qué harías?
```

Él piensa.

Mira sus caras.

Recuerda.

**No toda verdad necesita ser pronunciada.**

```
                            ÉL
                Probablemente lo mismo que tú.
```

La chica se ríe.

```
                            CHICA
                No tienes idea de lo que haría.
```

Él sonríe.

```
                            ÉL
                No. Pero pareció la respuesta correcta.
```

Todos ríen.

Él también.

Esta vez la risa dura un poco más.

### INT. SALÓN DE FIESTA - NOCHE

Música. Luces de colores. Gente apretada en grupos.

Él está irreconocible.

Camisa impecable.

Cabello arreglado.

Postura abierta.

Una mano en el bolsillo.

Una sonrisa perfectamente calibrada.

Se mueve entre grupos como si hubiera nacido allí.

Una persona se ríe.

Él encuentra el momento exacto para reír también.

Alguien cuenta un problema.

Él inclina ligeramente la cabeza.

```
                            ÉL
                Tiene sentido que te sintieras así.
```

La persona lo mira con alivio.

Otra persona llega.

```
                            CHICO
                ¿Cómo conoces a todos?
```

Él responde sin dudar.

```
                            ÉL
                No conozco a todos.
```

Sonríe.

```
                            ÉL
                Solo intento que nadie se sienta ignorado.
```

El chico sonríe.

Admirado.

Desde fuera, Él parece magnético.

Desde dentro...

Su sonrisa permanece.

Pero sus ojos recorren el salón contando variables.

**Volumen.
Distancia.
Tiempo de respuesta.
Contacto visual.
Risa.
Contacto físico: apropiado.**

Su mente trabaja sin detenerse.

Una persona le toca el hombro.

Él gira.

```
                            CHICA
                Eres increíblemente fácil de hablar.
```

Él mantiene la sonrisa.

```
                            ÉL
                Gracias.
```

Ella se aleja.

Su sonrisa tarda demasiado en desaparecer.

### INT. BAÑO DE LA FIESTA - NOCHE

La música llega amortiguada desde afuera.

Él entra solo.

Se queda frente al espejo.

Silencio.

Apoya ambas manos sobre el lavabo.

Respira.

Se mira.

El rostro perfecto.

La expresión correcta.

La postura correcta.

Todo correcto.

Se obliga a sonreír.

La sonrisa aparece.

Se obliga a mantenerla.

Cinco segundos.

Diez.

Quince.

Su mandíbula tiembla.

La sonrisa se quiebra.

Por primera vez en años, no intenta arreglarla.

Permanece mirándose.

En el espejo ya no ve al chico de antes.

Tampoco al hombre carismático de la fiesta.

Ve una colección de respuestas aprendidas.

Una máscara que, de tanto usarla, ha empezado a sentirse como una cara.

Se escucha una carcajada detrás de la puerta.

Él cierra los ojos.

```
                            ÉL
                Estoy cansado.
```

Lo dice en voz alta.

La frase parece sorprenderlo.

Abre los ojos.

### INT. PASILLO DEL INSTITUTO - DÍA

Una semana después.

Él camina.

Una compañera lo intercepta.

```
                            COMPAÑERA
                ¡Hey! ¡Ven con nosotros!
```

Él se detiene.

Mira al grupo.

Sonríe ligeramente.

```
                            ÉL
                No.
```

La compañera parpadea.

```
                            COMPAÑERA
                ¿No?

                            ÉL
                Hoy no quiero.
```

Un silencio pequeño.

Incómodo.

La compañera se encoge de hombros.

```
                            COMPAÑERA
                Vale.
```

Se marcha.

Él sigue caminando.

No siente culpa.

Tampoco triunfo.

Solo alivio.

### EXT. AZOTEA DEL INSTITUTO - TARDE

Cielo naranja.

El ruido de la ciudad llega lejano.

Él está sentado junto al muro.

Tiene la libreta abierta.

Pasa página por página.

**NO PREGUNTAR DEMASIADO.**

**SONRÍE.**

**NO DIGAS TODO LO QUE PIENSAS.**

**MIRA A LOS OJOS.**

**RECUERDA LOS NOMBRES.**

**DEJA HABLAR.**

**HAZ PREGUNTAS.**

**RÍETE.**

**NO SEAS INTENSO.**

**NO SEAS FRÍO.**

**NO SEAS RARO.**

Se detiene.

Mira todas las reglas.

Durante unos segundos parecen mandamientos.

Luego arranca la página.

La dobla.

La guarda en el bolsillo.

No la destruye.

Solo deja de mirarla.

Un chico aparece por la puerta de la azotea.

Es MARCOS.

```
                            MARCOS
                ¿Qué haces aquí?
```

Él se encoge de hombros.

```
                            ÉL
                Nada.
```

Marcos se sienta a su lado.

Hay silencio.

Un silencio normal.

No necesita rellenarlo.

Marcos mira el cielo.

```
                            MARCOS
                Qué día tan raro.
```

Él contempla las nubes.

```
                            ÉL
                Sí.
```

Pausa.

```
                            ÉL
                Me gustan más los días así.
```

Marcos lo mira.

```
                            MARCOS
                ¿Así cómo?
```

Él busca las palabras.

No consulta ninguna regla.

```
                            ÉL
                En los que no tengo que hablar con nadie.
```

Marcos suelta una pequeña risa.

```
                            MARCOS
                Qué sincero.
```

Él casi sonríe.

```
                            ÉL
                Estoy practicando.
```

Marcos ríe otra vez.

Él también.

Esta vez no estudia cuándo.

No calcula cuánto.

No observa la reacción de nadie.

Simplemente se ríe.

### INT. CAFETERÍA - DÍA

Mismo lugar.

Mismo ruido.

Él está sentado con varias personas.

Escucha una conversación.

Alguien dice algo absurdo.

Todos ríen.

Él no.

Mastica.

La persona lo mira.

```
                            CHICA
                ¿No te dio risa?
```

Él piensa un segundo.

```
                            ÉL
                No.
```

Pausa.

```
                            ÉL
                Pero me caes bien.
```

La chica sonríe.

```
                            CHICA
                Eso es muchísimo más raro.
```

Él asiente.

```
                            ÉL
                Lo sé.
```

Ella le pasa una patata de su bandeja.

```
                            CHICA
                Toma.
```

Él la acepta.

Por un instante, sus hombros se relajan.

Ya no está interpretando a alguien.

Ya no está intentando convertirse en una versión perfecta de sí mismo.

Sigue siendo serio.

Sigue siendo silencioso.

A veces sigue diciendo cosas inconvenientes.

Pero ahora sabe cuándo detenerse.

Cuándo escuchar.

Cuándo preguntar.

Cuándo marcharse.

Cuándo quedarse.

Mira alrededor de la mesa.

Las personas siguen hablando.

Cambian de opinión.

Se ofenden por cosas pequeñas.

Se ríen cuando nadie entiende por qué.

Dicen "no pasa nada" cuando claramente pasa algo.

Se preguntan "¿qué tal?" sin esperar siempre una respuesta.

Él observa todo aquello.

Ya no como un científico.

Tampoco como un imitador.

Simplemente como alguien que, después de mucho tiempo, empieza a comprender que los humanos no son sistemas que deban resolverse.

Son sistemas que improvisan.

Él toma otra patata.

```
                            ÉL
                Mañana no quiero venir.

                            MARCOS
                ¿Y eso?

                            ÉL
                Estoy cansado.
```

Marcos asiente.

```
                            MARCOS
                Yo también.
```

Pausa.

```
                            ÉL
                Entonces estamos de acuerdo.
```

Se miran.

Sonríen.

La conversación continúa.

La cámara se aleja lentamente de la mesa.

Por primera vez, Él no está pensando en cómo debe verse desde afuera.

Está ahí.

Simplemente ahí.

**FADE OUT.**
